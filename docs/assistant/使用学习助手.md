# 使用学习助手

网页版本适合直接阅读、查公式和运行交互实验；Clone 仓库后，还可以让能够读取仓库文件的对话助手按课程进度提问、批改与复习。两种方式使用同一套教材，但只有 Clone 模式能在本机持续保存个人状态。

## 1. Clone 并打开仓库

```bash
git clone https://github.com/SamKuler/analog-electronics-guide.git
cd analog-electronics-guide
```

在支持仓库级说明的编码助手中打开这个目录。助手应自动读取根目录的 `AGENTS.md`；如果当前工具不会自动读取，可把仓库根目录 `prompts/学习助手.md` 的内容复制到对话中。

## 2. 用一句口令开始

| 口令 | 作用 |
| --- | --- |
| `开始第 N 天` | 进入 Day 1–30 中指定的一天 |
| `只做 P0` | 当天只保留最低完成线 |
| `批改 <题号>` | 按六层证据批改一次独立尝试 |
| `开始模拟面试` | 隐藏答案并按题本计时追问 |
| `复盘` | 找出最早断点并安排最小修复 |
| `查看到期复习` | 列出到期或逾期的 D+1/D+3/D+7 项 |

例如：

```text
开始第 1 天
批改 E-C-01
查看到期复习
```

学习助手会先让你作答，再给提示和反馈。若一开始就要求完整答案，主动学习与面试训练的效果会明显下降。

## 3. 本地状态与隐私

首次开始实际学习时，助手会在仓库中创建：

```text
.learning/
├── state.md
├── errors.md
└── reviews.md
```

- `state.md` 保存当前 Day、完成情况和关卡结果；
- `errors.md` 保存原答、最早断点、修正依据和最小变式；
- `reviews.md` 保存 D+1、D+3、D+7 到期日与历史结果。

`.learning/` 已写入 `.gitignore`，不会随普通 Git 提交进入公开仓库。它仍是本机文件：请按所用对话工具的隐私政策决定是否输入敏感内容，并避免把真实姓名、申请信息或其他个人数据写进公开 issue、提交或分支。

网页版本没有账号、数据库或进度脚本，因此不会自动同步这些状态。换设备时，如需迁移学习记录，请自行通过可信的私有方式复制 `.learning/`。

## 4. 学习助手怎样批改

一次答案会从六层检查：

1. 结论；
2. 模型与器件状态；
3. 变量与参考方向；
4. 方程、计算与单位；
5. 量纲、极限或数量级自检；
6. 适用边界与口头表达。

助手先修最早出错的一层，再给一道只改变一个条件的变式。只有独立通过变式，错题才会被标为“已修复”。

## 5. 常见问题

### 助手直接把答案说出来了

重新粘贴提示词，并明确说：“遵守 attempt-before-answer；先只给不包含结论的一级提示。”

### 助手没有保存进度

确认当前工具拥有仓库写权限，并让它执行 `复盘`。正常学习只能写 `.learning/`，不应修改 `docs/`。

### Git 显示了学习记录

先确认文件确实位于 `.learning/`，再检查仓库根目录 `.gitignore` 是否包含 `.learning/`。如果文件曾被手动加入 Git，需先从 Git 索引移除后再继续使用；不要把记录复制进公开目录。

### 只想使用网页

直接从[第 1 天](../sprint/week-1.md#day-1)开始即可。网页不会自动更新进度，可以使用纸面或自己的私有笔记记录关卡结果。
