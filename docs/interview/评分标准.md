# 面试评分标准与复盘表

本量表用于[两套模拟面试](两套模拟面试.md)，也可用于任意 5～10 分钟口试。它评价的是“能否给出可验证的电路分析”，不是口音、话术或与某种未公开面试风格的相似度。

## 1. 两类分数与通过条件

每次保留两类互不替代的分数：

1. **题目分 $P_{item}$：** 按模拟题中每项分值累加，满分 100，用于定位哪条知识链断裂。
2. **维度总评 $P_{rubric}$：** 按本页五个固定维度计算，满分 100，是“面试可用”的主分数。

通过必须同时满足：

- $P_{rubric}\ge80.0$；
- $P_{item}\ge80$；
- 没有未清除的关键失误；
- 任一已抽到的 P0 模块得分不低于该模块可得分的 60%。

若两类分数相差超过 10 分，回听录音并找出证据归类错误；不取平均来掩盖分歧。60～79.9 分进入定向修复，低于 60 分返回最早的 P0 依赖点。

### 1.1 P0 模块归属与归一化规则

七个模块代码固定为：C 电路基础、D 二极管、T 晶体管、A 基本放大器、O 运算放大器、F 反馈与频率响应、S 差分/功放/电源与模拟接口。为避免同一道综合题被重复计分，每个模拟题的**全部分值只归入一个主模块**；题目虽可能跨章，模块小计也不拆分。

对某套模拟、某模块 $X$，先把归属于 $X$ 的题目实得分相加为 $E_X$，把同一批题的可得分相加为 $A_X$，再计算

$$
M_X=\frac{E_X}{A_X}\times100\%.
$$

计算达标与否时不先四舍五入；展示时再保留一位小数。只有 $A_X>0$ 的模块算“已抽到”：$M_X\ge60\%$ 达标，$M_X<60\%$ 不达标。分母为 0 的 C/D 在模拟二标“未采样”，既不算通过也不算失败。单套模拟判定只检查该套已采样模块；完成两轮后的最终判定要求模拟一与模拟二各自的已采样模块都没有低于 60%。

## 2. 固定权重与计算

| 维度 | 符号 | 固定权重 |
|---|---|---:|
| 正确性 | $C$ | 35% |
| 推理与推导 | $R$ | 30% |
| 电路图与波形 | $D$ | 15% |
| 边界条件与纠错 | $B$ | 10% |
| 表达清晰度 | $E$ | 10% |
| **合计** |  | **100%** |

考官对每一维只选择 $0,50,80,100$ 四个原始等级之一，不在等级间凭印象插值。总评为

$$
\boxed{P_{rubric}=0.35C+0.30R+0.15D+0.10B+0.10E}.
$$

最后保留一位小数。例如 $C=80,R=80,D=50,B=100,E=80$，则

$$
P_{rubric}=28+24+7.5+10+8=77.5.
$$

### 2.1 正确性 C（35%）

| 原始等级 | 可观察描述 |
|---:|---|
| 0 | 核心状态、方向或结论错误；数值与基本物理矛盾，且在追问后仍未纠正。 |
| 50 | 能答对部分定义或趋势，但至少一个主结论错误，或计算结果缺单位/符号导致不可用。 |
| 80 | P0 主结论、方向、数量级正确；存在一处不改变主结论的算术、近似或术语瑕疵。 |
| 100 | 所有主结论和关键数值正确；主动用单位、符号、数量级或替代方法交叉检查。 |

### 2.2 推理与推导 R（30%）

| 原始等级 | 可观察描述 |
|---:|---|
| 0 | 只猜结论或背公式，无法从 KCL/KVL、元件关系或定义建立方程。 |
| 50 | 有局部因果或方程，但跳过关键步骤；模型、未知量或参考方向含混，追问后链条仍断裂。 |
| 80 | 能按“假设—模型—方向—方程—求解”完成主链；一处次要变形或论证略跳步。 |
| 100 | 推导闭环完整，并用极限、量纲、工作区或另一种表示验证；能说明为何选该模型。 |

### 2.3 电路图与波形 D（15%）

| 原始等级 | 可观察描述 |
|---:|---|
| 0 | 图缺少关键连接，或电源/地/端子错误，使后续分析对象已改变。 |
| 50 | 拓扑大体可辨，但参考方向、极性、坐标、静态值或换态点缺失两项以上。 |
| 80 | 电源、地、端子、输入输出与主要参考方向齐全；波形相位/拐点正确，仅有一处次要标注遗漏。 |
| 100 | 原电路、等效图和波形彼此一致；标明单位、Q 点/阈值/削顶或渐近区，并能由图反查方程符号。 |

### 2.4 边界条件与纠错 B（10%）

| 原始等级 | 可观察描述 |
|---:|---|
| 0 | 把近似说成无条件真理；反例出现后辩解或改题，未定位失效假设。 |
| 50 | 被追问后能说“有非理想”，但不能指出具体工作区、频率、幅度、负载或电源限制。 |
| 80 | 主动声明至少一个决定性边界；发现错误后能撤回错误部分并保留仍有效的结论。 |
| 100 | 系统检查模型、工作区、供电/负载和动态限制；用反例定位失效步骤，给出可测量、可证伪的修正结论。 |

### 2.5 表达清晰度 E（10%）

| 原始等级 | 可观察描述 |
|---:|---|
| 0 | 长时间无结论，符号多次变换且不说明，考官无法还原分析。 |
| 50 | 能表达部分内容，但顺序混乱、答非所问或大量堆术语，需要考官重组。 |
| 80 | 使用“先结论—后原因—必要公式—边界—回扣”，在时限内基本完整；有一处冗余或术语未定义。 |
| 100 | 首句直接、符号稳定、层次清楚；知道何时停下，也能在信息不足时精确说出所需条件。 |

## 3. 关键失误规则

关键失误不靠其他维度高分抵消。发生后仍记录数值分，便于观察进步，但本轮结果标为 **FAIL—关键失误未清除**。

### K1　市电/高能量源不安全

若考生建议在裸露市电上带电改线、触碰测量，或在未知高能量电源上省略隔离、限流、放电和额定值检查，考官立即停止相关操作题，本轮不通过。学习阶段只使用隔离的安全低电压电源；涉及市电的整流拓扑只做纸面分析或使用合规隔离设备并由有资质人员监督。

### K2　虚短误用且拒绝状态检查

若把虚短用于正反馈、比较器、输出饱和或明显动态越界的运放，考官只提示一次“请检查反馈方向和输出状态”。仍坚持原结论则记 K2，本轮不通过。若考生在提示后立即定位并完整重算，K2 可清除，但边界与纠错不得评 100。

### K3　使用未经验证且与数据冲突的模型

若在数值答案中直接假定二极管导通、BJT 前向有源、MOS 处于饱和区或小信号线性，而题给电压/摆幅已与假设冲突，考官只提示一次“请回代验证模型”。仍不验证或继续用冲突结果则记 K3，本轮不通过。单纯未口述一个不影响结论的次要近似不自动触发 K3。

关键失误清除意味着：明确撤回错误结论、指出失效假设、从基本模型重算，并用一个新参数或测量验证；只说“我刚才口误”不算清除。

## 5. 只选三个缺口的复盘规则

### 5.1 先找“最早断点”

一个错误可能表现为算错增益，但最早断点可能是参考方向、工作区或等效图。每条错误只登记最早可修复原因并按错题类型归档，避免把同一根因拆成五个任务。

### 5.2 用依赖、频率、严重度排序

对每个候选缺口给三个整数等级：

| 因素 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 依赖 $d$ | 非知识缺口 | 孤立 P2 | 单模块后续依赖 | 跨两模块依赖 | — |
| 频率 $f$ | 未观察到 | 出现一次 | 同一模拟重复 | 两套/多链重复 | — |
| 严重度 $s$ | 无实质影响 | 表达/算术 | 边界或局部推理 | 主结论/模型错误 | K1/K2/K3 关键失误 |

计算

$$
P_{gap}=4d+3f+4s.
$$

先把所有 $s=4$ 的未清除关键失误列在前面，再按 $P_{gap}$ 从高到低排列其余缺口；同分时依次比较 $s>d>f$，再选知识链中更早的断点。**行动清单严格只保留前三项。** 其余只留在错误记录中，不在本周展开；若未清除关键失误超过三项，本轮仍不通过，但也只先修优先级最高三项。

### 5.4 D+1 / D+3 / D+7 动作

每个缺口只安排三次短回访：

- **D+1：恢复。** 不看资料用 30 秒说结论和边界；再从 KCL/KVL、器件方程或定义重做原题的最短一步。若错，回到对应 P0 小节，不增加新题。
- **D+3：变式。** 只改变一个参数、参考方向、负载或频率，画图并在 90 秒内完成“预测—方程—验证”。目标是证明不是背原答案。
- **D+7：迁移。** 做一道跨章节题或从[高频问题树](高频问题与追问.md)抽同链追问；按本页五维重新评分。达到 80 且无关键失误才关闭该缺口。

|---|---|---|---|---|

复盘的目标不是把记录表填满，而是用最少动作修复最高依赖、最高频且最严重的三条知识链，然后回到其余四门专业课的总时间安排。
