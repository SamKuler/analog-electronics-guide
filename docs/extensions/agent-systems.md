# 智能系统中的模拟边界

这一页是可选拓展。主线教材只要求理解通用链路：

**传感器 → 模拟前端 → ADC → 数字处理/控制 → 驱动器 → 执行器**

纯软件智能体并不因为使用“智能体”概念就需要模拟电子技术；只有当系统与真实传感、采样、电源或执行硬件发生联系时，下面这些模拟边界才成为设计问题。

如果数字处理环节使用机器学习模型或自主智能体，模拟电子技术的位置并没有改变：它仍负责把真实世界中连续、微弱且带噪的信号可靠地送入数字系统，并把数字系统的决定转换为执行器可用的电压、电流和功率。

## 信息进入数字系统之前

传感器输出常常幅度小、源阻抗高，并叠加共模干扰、漂移和宽带噪声。模拟前端需要完成放大、阻抗变换、滤波、偏置和保护，同时确保输出没有超过 ADC 的输入范围。

这里有一个不可逆边界：若前端已经削顶，或信号在采样前发生混叠，后续算法通常不能恢复原始信息。算法可以估计噪声，却不能凭空重建从未被正确采集的物理量。

## 数字系统与模拟部分相互影响

数字电路并不与模拟部分完全隔离。时钟边沿、开关电流和通信活动会通过公共电源阻抗、地回流、寄生电容和电磁耦合进入模拟链。去耦、滤波、接地、布局和电源完整性因此同时影响 ADC 的有效精度与模型输入质量。

## 决策离开数字系统之后

GPIO、DAC 或 PWM 通常只给出控制信号，不能直接代表执行器所需功率。电机、扬声器、加热器和电磁阀需要驱动级、功率器件、保护、反馈与热设计。输出电流限制、电源压降和温升会改变动作结果，也可能反过来污染传感链。

## 一个适合口述的分析框架

面对“模电与智能系统有什么关系”时，可以依次说明：

1. 传感器产生什么量级、什么带宽、什么源阻抗的信号；
2. 模拟前端如何放大、滤波、偏置并避免饱和；
3. ADC 的量程、采样率、量化与前端噪声如何共同决定可用信息；
4. 数字处理或智能决策依赖哪些没有被破坏的观测；
5. 驱动器怎样把逻辑量转换为执行器需要的电压、电流和功率；
6. 电源、地、时钟和热如何跨越各模块形成耦合。

这种表达把智能算法放在完整物理闭环中，但不把算法本身误称为模拟电子技术。
